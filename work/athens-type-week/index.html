Covers & Posters · 2024

Athens Type Week

Posters for a typography festival, produced in five sizes on the same press sheet to keep the print run inside a volunteer budget.

Client
Athens Type Week
Role
Poster series
Year
2024
Category
Covers & Posters

The festival had no budget for varied print runs, so the whole campaign had to be imposed on one sheet.

Working within that limit set the layout: a single scaled letterform per poster, the same two inks throughout, and information typeset small at the foot. The constraint became the identity.
