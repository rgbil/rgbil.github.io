Twelve covers for a small press reissuing translated European fiction, designed to be recognisable as a set from across a bookshop.

A series only works if the individual books are distinct and the shelf is not.

One letterform per title, cropped hard and printed in a single flood colour, gives each cover its own character while the format stays identical. Spines align into a continuous band when the set is shelved in order.
